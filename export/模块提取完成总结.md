## 🎯 核心功能

### 1. 数据构建器 (`core/builder.py`)

**功能**:
- ✅ 自动发现并配对 message/orderbook CSV 文件
- ✅ 数据集划分 (train/val/test)
- ✅ 完整的数据处理流程编排
- ✅ 数据持久化 (pkl 格式)
- ✅ 静态方法加载已处理数据

**关键方法**:
```python
builder = LOBSTERDataBuilder()
datasets = builder.build_dataset("./data")
datasets = LOBSTERDataBuilder.load_processed_data("./data")
```

### 2. 预处理器 (`core/preprocessor.py`)

**功能**:
- ✅ Message 数据预处理
  - 时间差分计算
  - 价格缩放 (除以10000)
  - 方向标记处理
- ✅ Orderbook 数据预处理
  - 10档盘口处理
  - 价格缩放
- ✅ 相对价格归一化

**关键类**:
```python
MessagePreprocessor.load_csv(path)
MessagePreprocessor.preprocess(df)
OrderbookPreprocessor.load_csv(path)
OrderbookPreprocessor.preprocess(df)
```

### 3. 标签生成器 (`core/labeler.py`)

**功能**:
- ✅ 基于止损/止盈的二分类标签
- ✅ Long/Short 策略支持
- ✅ 可配置参数（止损阈值、止盈倍数、观察窗口）
- ✅ 策略模式设计（易于扩展）

**关键类**:
```python
strategy = StopLossLabelStrategy(
    stop_loss_ticks=6,
    take_profit_ratio=1.5,
    is_long=True
)
labels = strategy.generate(message_df, orderbook_df)
```

### 4. 归一化工具 (`core/normalizer.py`)

**功能**:
- ✅ Z-score 归一化
- ✅ 基于训练集计算全局统计量
- ✅ 参数持久化和加载
- ✅ 分别处理 message 和 orderbook

**关键类**:
```python
normalizer = ZScoreNormalizer()
normalizer.fit(train_data)
normalized_data = normalizer.transform(test_data)
normalizer.save_params("norm_params.csv")
```

### 5. PyTorch 加载器 (`loaders/pytorch.py`)

**功能**:
- ✅ 继承 `torch.utils.data.Dataset`
- ✅ 固定窗口长度序列提取
- ✅ 全局索引映射（跨文件边界）
- ✅ 便捷函数创建 DataLoader

**使用方式**:
```python
train_loader, val_loader, test_loader = get_dataloaders(
    data_path="./data",
    batch_size=32,
    seq_len=128,
    label_type='long'
)
```

### 6. aeon 适配器 (`adapters/aeon.py`)

**功能**:
- ✅ 滑动窗口提取
- ✅ 价格列滑动归一化
- ✅ channels-first 布局 `(n_instances, n_channels, window_size)`
- ✅ 元数据保留

**使用方式**:
```python
datasets = build_datasets(
    data_path="./data",
    window_size=64,
    step=32,
    label_kind='long'
)
```

## 🔧 设计特点

### 1. 模块化设计
- **核心模块** (`core/`): 无框架依赖，纯数据处理
- **加载器** (`loaders/`): 框架特定的数据加载
- **适配器** (`adapters/`): 框架格式转换

### 2. 简洁优雅的代码
- 每个模块职责单一
- 函数和类命名清晰
- 充分的文档字符串
- 类型提示 (type hints)

### 3. 易于扩展
- 标签策略基类 (`LabelStrategy`)
- 归一化器可扩展
- 适配器模式支持新框架

### 4. 三层 API 设计

**顶层 API** (最简单):
```python
from lobster_toolkit import build_dataset
datasets = build_dataset("./data")
```

**中层 API** (灵活配置):
```python
from lobster_toolkit.core import LOBSTERDataBuilder
builder = LOBSTERDataBuilder(stop_loss_ticks=10)
datasets = builder.build_dataset("./data")
```

**底层 API** (完全控制):
```python
from lobster_toolkit.core import preprocessor, labeler
# 手动控制每个步骤...
```
